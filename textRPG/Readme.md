# textRPG
## cli 로그라이크 

### 구현 컨텐츠
#### 전직 및 각성
* <b>경험치</b> - 전투,이벤트,파밍등의 행위를 통해 획득. 
* <b>레벨</b> - 요구 경험치만큼 소모하여 자동으로 다음 레벨로 진급. 
* <b>스탯포인트</b> - 레벨이 증가할 시 일정량의 포인트를 지급 받고 소모하여 특정 스탯을 강화
* <b>전직</b> - 특정 레벨 도달시 새로운 스킬을 획득 
* <b>스킬</b> - 전직, 이벤트, 파밍등을 통해 스킬을 강화 또는 획득. 스킬은 특정 개수 이상 보유 할 수 없음

#### 파밍
* 파밍 가능한 지역에 도달시 주어진 횟수만큼 파밍을 시도하여 아이템을 획득하거나 이벤트에 돌입
#### 전투
* 턴 - 적과 플레이어가 1회씩 행위를 주고받음. 속도가 빠른 측이 먼저 행위를 실행.
* 전투 - 적과 플레이어는 공격,방어,도망,아이템사용을 선택할 수 있음.
* 공격 - 공격시 일반공격 혹은 스킬을 사용할 수 있음. 스킬의 경우 현재 보유한 mp를 소모하여 사용.
* 방어 - 방어시 방어측의 방어력만큼 상대의 공격 데미지를 감소시킴.
* 도망 - 일정 확률로 현재 전투에서 도망침. 상대의 속도를 크게 상회할 경우 확률이 높아짐.
* 처치 - 적을 처치한 경우 해당 적에 맞는 경험치와 확률성 아이템을 획득. 
* 사망 - 적에게 공격당하여 체력이 0이하로 떨어질 경우 사망 처리 후 게임 종료.
