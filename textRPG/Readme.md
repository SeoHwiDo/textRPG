# textRPG
## CLI 로그라이크 RPG 프로젝트

### 프로젝트 개요
이 프로젝트는 콘솔 기반으로 진행되는 턴제 텍스트 RPG를 목표로 설계된 코드 샘플입니다. 현재는 캐릭터 상태와 기본 전투 행동 구조를 정리하는 단계까지 진행되었습니다.

### 현재 구현 진행도
#### 완료된 내용
- 캐릭터 기본 상태 모델링
  - 이름, 체력, 마나, 골드, 레벨, 경험치 관리
  - 힘, 민첩, 건강, 지혜, 매력 같은 기본 스탯 구조
  - 장비 슬롯(무기/방패)과 장비 데이터 구조
- 행동 선택 구조
  - 공격, 스킬, 방어, 도망, 아이템 행동을 선택하는 흐름 구현
  - 선택된 행동에 따라 `basic_attack`, `skill_attack`, `runOut`가 연결되도록 구성
- 전투 턴 구조 초안
  - 선공 판단, 턴 교대, 전투 종료 조건 판단 흐름을 정리
- 기본 스킬 데이터 구조
  - 스킬 이름, 피해량, MP 소모량을 담는 구조를 마련

#### 아직 미구현/보완 필요
- 메인 게임 루프
  - 시작 화면, 플레이어 생성, 맵 이동, 이벤트 선택 흐름이 필요함
- 적군/몬스터 시스템
  - 적 데이터, 적 AI, 전투 중 적 행동 처리
- 실제 스킬 시스템
  - 스킬 종류별 효과, MP 소모, 쿨타임, 전직 연계 로직
- 아이템/장비 강화 시스템
  - 획득, 사용, 강화, 교체 로직
- 레벨업/전직/경험치 시스템
  - 경험치 기반 레벨업, 스탯 포인트, 직업 전직
- 이벤트/파밍/지역 시스템
  - 지역별 탐험, 이벤트 확률, 보상 로직

### 구현 우선순위
1. 메인 루프 구현
2. 몬스터 생성 및 전투 테스트 흐름 구성
3. 스킬과 아이템 사용 로직 보강
4. 레벨업/전직/장비 강화 연동
5. 게임 종료 조건과 저장/불러오기 흐름 추가

### 현재 코드 상태 요약
- [textRPG/Actor.cpp](textRPG/Actor.cpp): 캐릭터 상태와 전투 행동 로직의 기본 골격이 정리됨
- [textRPG/Fight.cpp](textRPG/Fight.cpp): 턴제 전투 흐름의 틀을 구성함
- [textRPG/Skill.cpp](textRPG/Skill.cpp): 스킬 데이터 구조와 기본 반환값을 마련함
- [textRPG/playerStat.cpp](textRPG/playerStat.cpp): 플레이어 관련 상태 클래스의 기본 구조를 구성함
- [textRPG/main.cpp](textRPG/main.cpp): 진입점과 기본 캐릭터 생성 흐름을 추가함
